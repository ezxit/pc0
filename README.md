# 論仁・論君子

中文科 HTML 簡報，依提供的課本照片，選取《論語・里仁》前三則。

線上簡報：https://ezxit.github.io/pc0/

## 內容與時間

| 頁 | 內容 | 建議秒數 |
|---|---|---:|
| 1 | 封面 | 5 |
| 2 | 朗讀第一、二則，完整原文 | 20 |
| 3 | 朗讀第三則，完整原文 | 34 |
| 4 | 翻譯第一、二則 | 23 |
| 5 | 翻譯第三則 | 27 |
| 6 | 解讀思想 | 23 |
| 7 | 解讀粵音 | 35 |
| 8 | 生活應用 | 28 |
| 9 | 總結 | 15 |
| | 合計 | **210** |

五部分依序為：朗讀、翻譯、解讀、生活應用、總結。時間屬建議，實際講述長短受語速與停頓影響；完整講稿見 [講稿.md](講稿.md)。

## 使用

- 普通模式可用左右方向鍵或畫面下方按鈕翻頁；上方導覽可直達各部分。
- `F` 切換全螢幕，`Esc` 退出全螢幕；`N` 顯示或收起講者稿。
- 全螢幕時隱藏下方控制列與底部進度條，使用左右方向鍵翻頁。
- 所有頁面由講者手動切換；上方時間表僅供安排講述節奏。
- 中文使用本機宋體，未安裝時使用 Noto Serif TC 的繁體子集；英文、數字及粵拼使用提供的 `claudefont.ttf`。

直接以靜態網站伺服器提供本目錄，不需建置或第三方腳本。若本地預覽，可使用 `python -m http.server 8097`，然後開啟 `http://localhost:8097/`。
